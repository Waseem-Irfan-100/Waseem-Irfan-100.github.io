# waseem-irfan-100.github.io

Personal site of **Syed Waseem Irfan**: CS at IIIT Kottayam, research intern at IIIT Hyderabad.

Live at **https://waseem-irfan-100.github.io**

## What's here

```
index.html          the whole site (HTML + CSS, no build step)
waseem.jpg          profile photo
favicon.svg         browser tab icon
.nojekyll           tells GitHub Pages to serve files as-is
```

## Editing

Everything is in `index.html`. Open it in any browser to preview.

- **Projects** are in the `Things I've made` list (`<ol class="log">`). Copy one `<li>` to add another.
- **Margin notes** are `<span class="note">` elements; **highlighter** is `<mark>`.
- **Colours and fonts** are the variables at the top of the `<style>` block.

## Publishing

Push to the `main` branch. GitHub Pages serves it automatically
(Settings → Pages → Source: *Deploy from a branch*, `main` / root).
